# Huzaifa Ahmad: portfolio

Live at **https://hahmad10.github.io**

Built with React, TypeScript, Tailwind CSS and Vite. Every push to `main` builds the site and deploys it to GitHub Pages (see `.github/workflows/deploy.yml`).

## Editing content

All text lives in `src/data.ts`: nav links, focus areas, highlights, experience and projects. The resume is `public/Huzaifa_Ahmad_Resume.pdf`.

## Running locally

```sh
npm install
npm run dev
```
